# Mole PvP
A new PvP mode created with BattleArena

## Gamemodes
**Teams**
- 1v1 (mole)
- 2v2 (mole_2v2)
**FFA**
- last one standing (mole_everyone)
- most kills (mole_most_kills)

comming soon...

## Setup
1. Install all [required plugins](required_plugins.md)
2. Copy Battlearena/ in your plugins folder
3. Copy TNTimer/ in your plugins folder
4. Go to your Map
5. pick your gamemode and run /<gamemode-alias> create ([gamemodes](#gamemodes) for more information)
6. read [additional notes](additional_notes.md)
